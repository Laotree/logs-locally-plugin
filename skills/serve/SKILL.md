# Serve Log Viewer

Run `llp serve` to start the local web UI for browsing Claude Code session logs.

The web UI will be available at `http://127.0.0.1:8484` by default.

Features:
- Session list with search and filters (by model, time range, keyword)
- Message detail view with thinking blocks and tool calls  
- Live auto-refresh
- Dark theme inspired by Claude's web design
